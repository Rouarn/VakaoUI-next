# Roadmap 与维护策略

## 版本策略

- 版本固定为 `0.1.0`：发布采用**同版本覆盖发布**（用同一版本号重复发布直接覆盖制品），日常修复与新增都复用 `0.1.0`，**不需要升版本号**；覆盖内容可能包含破坏性变更，会在 CHANGELOG 中逐条标注。
- 进入 `1.0.0` 后遵循 SemVer：破坏性变更只出现在主版本。
- 每个对外可见变更都需要 Changeset；发布由维护者手动触发。

## API 稳定性约定

- 已发布组件的 props、事件与插槽名称在次版本内保持兼容。
- 新增能力优先通过可选 props 与插槽扩展，不改变既有默认行为。
- 样式类名 `vk-*` 与 CSS 变量 `--vk-*` 视为公共契约；内部结构类名可能调整，请勿依赖。

## 废弃策略

1. 在文档与类型注释中标记 `@deprecated`，说明替代方案。
2. 至少保留一个次版本的过渡期，并在控制台给出一次性提示。
3. 主版本发布时移除，并在 CHANGELOG 的 Breaking Changes 中列出。

0.1.0 为全新项目，无历史兼容包袱，也不提供旧版本迁移路径。

## 近期计划

### 后续计划（仍以 0.1.0 发布）

- Select：多选、远程搜索、分组选项
- Table：固定表头、列宽拖拽、行选择
- Grid：响应式断点
- Drawer / Tooltip / Popconfirm 定位增强
- 视觉回归接入截图对比服务

### 0.3.0

- DatePicker / TimePicker 与日期适配层
- Upload、Tree、Transfer
- 表单 schema 渲染与更完整的校验联动

### 1.0.0

- API 冻结与 SemVer 承诺
- 主题编辑器与令牌导出
- 完整的键盘与读屏测试矩阵
