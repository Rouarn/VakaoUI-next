# 设计令牌

令牌分两层：`src/tokens/brand.json` 保存品牌原始值，`src/tokens/theme.json` 保存语义映射。运行时的 `--vk-*` CSS 变量、`theme.css`、`themeOverrides` 都从这两份文件派生，不允许在组件里另造值。

## 2. 颜色映射

### 2.1 强调色：从灰蓝到朱砂

品牌原始 accent 是 `#46A6C6`，饱和度只有 53%，用作实心按钮时白字对比度 2.65:1、用作纸面文字 2.47:1，都不满足 AA。早期版本先改成低饱和的潮汐青 `#0B6F86`：对比度达标，但视觉偏灰、偏冷，用户反馈"像不知道哪来的蓝色"，与纸面 / 四色星的气质脱节。

0.1.0 换成**朱砂 `#C43A21`**。取色方法：从品牌橙 `#F0995F` 出发，色相往红移约 12°，饱和度提到 74%，明度压到 44%。理由：

- **有温度**：`#C43A21` 与纸面 `#F3F1EC` 同属暖调，像朱砂印在纸上；冷色 UI 贴在米色背景上正是早期版本的问题。
- **够醒目、面积小**：只用于实心按钮、选中态、focus ring、链接；大面积仍是纸色与墨色。
- **双项过 AA**：对纸面 4.68:1，白字压在上面 5.03:1。
- **与四色星协调**：朱砂是橙的深色延伸，与 warning 橙 L 差 30% 以上，不会混淆；与 info 蓝形成冷暖对照。
- **暗色可提亮**：暗色改用 `#FF8A5B`（对深底 8.07:1），按钮文字改用深墨 `#171210`（8.00:1）。

| 候选           | 色值      | 白字 / 按钮 | 纸面文字 | 结论                    |
| -------------- | --------- | ----------- | -------- | ----------------------- |
| 朱砂（采用）   | `#C43A21` | 5.03        | 4.68     | 双项过 AA，暖调最贴纸面 |
| 朱红（更亮）   | `#D8402A` | 4.48        | 4.17     | 白字差 0.02，放弃       |
| 赭石（更暗）   | `#8F2917` | 8.00        | 7.45     | 对比度富余，观感偏"砖"  |
| 潮汐青（旧值） | `#0B6F86` | 5.49        | 5.12     | 达标但冷灰，已替换      |
| 品牌原 accent  | `#46A6C6` | 2.65        | 2.47     | 不达标，禁止使用        |

## 3. 状态色（四色星映射）

### 3.1 映射与理由

四个语义色全部从四色星取，不新增色相。主色朱砂不参与状态表达。

| 语义      | 取自         | 理由                                                                                                                                                                |
| --------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `success` | 黄 `#EDDF55` | 四色里黄是唯一的高亮 / 达成色，品牌本身把它用于标签与数据；success 属于非紧急的正向反馈，允许高明度。红、绿不在品牌色内，黄比紫更接近"完成、点亮"的语感。           |
| `warning` | 橙 `#F0995F` | 橙是四色星里明度最高的暖色，与朱砂主色同族但明度差 30% 以上；状态位只出现在浅底 + 图标里，不会与主按钮混淆。                                                        |
| `error`   | 紫 `#A27FC2` | 红不在品牌色内。剩余可选的紫与黄中，紫是四色里明度最低、观感最"严肃"的一色，适合承担失败 / 危险；黄过亮且轻快，不适合错误。紫与橙、蓝都拉开色相，错误态不会被误读。 |
| `info`    | 蓝 `#5FBEDC` | 蓝是四色星里唯一的冷色，与朱砂主色形成冷暖对照：主色承担操作，蓝色承担陈述与系统提示。                                                                              |

### 3.2 每个语义四个令牌

| 令牌                      | 用途          | 规则                                                                                     |
| ------------------------- | ------------- | ---------------------------------------------------------------------------------------- |
| `--vk-color-<sem>`        | 基础色 / 指示 | 图标、圆点、进度条、实心标签。可直接用原色                                               |
| `--vk-color-<sem>-bg`     | 浅底          | 亮色为原色 12% 叠在卡片上的实色；暗色为 20%。必须与 `-text` 成对使用                     |
| `--vk-color-<sem>-border` | 边框          | 亮色由同色相压暗到对卡片 ≥ 3:1；暗色直接用基础色（基础色在深底上已 ≥ 5:1）               |
| `--vk-color-<sem>-text`   | 文字          | 亮色压暗到对 paper、card、自身浅底均 ≥ 4.5:1；暗色提亮到对深底 ≥ 4.5:1，只用于文字与图标 |

### 3.3 亮色具体值

括号内为 `-text` 对 paper / card / 自身 `-bg` 的实测对比度，均 ≥ 4.5:1。

| 语义    | `-`（base） | `-bg`     | `-border` | `-text`   | 对比度             |
| ------- | ----------- | --------- | --------- | --------- | ------------------ |
| success | `#EDDF55`   | `#F8F6E2` | `#9C9335` | `#6E6620` | 5.19 / 5.56 / 5.38 |
| warning | `#F0995F`   | `#F9EDE3` | `#C97F4E` | `#8F5730` | 5.21 / 5.58 / 5.11 |
| error   | `#A27FC2`   | `#EFEAEF` | `#A27FC2` | `#755A8E` | 5.15 / 5.52 / 4.90 |
| info    | `#5FBEDC`   | `#E7F2F2` | `#4C9AB3` | `#336D80` | 5.11 / 5.48 / 5.05 |

`error` 的 base 本身对卡片已有 3.14:1，因此 border 直接复用 base，不再派生，这是"原色够用就不派生"的示例。

### 3.4 暗色具体值

暗色不是亮色反相，四个语义都单独给值。`-border` 与 `-` 相同，因为基础色对深底已经足够可见；`-text` 逐项提亮，保证在 `-bg` 上仍 ≥ 4.5:1。

| 语义    | `-`（base） | `-bg`     | `-border` | `-text`   | 文字对暗底 / 卡片 / 浅底 |
| ------- | ----------- | --------- | --------- | --------- | ------------------------ |
| success | `#EDDF55`   | `#3D3A20` | `#EDDF55` | `#EDDF55` | 13.65 / 12.80 / 8.38     |
| warning | `#F0995F`   | `#402F22` | `#F0995F` | `#F5AC7B` | 9.89 / 9.27 / 6.72       |
| error   | `#A27FC2`   | `#332B36` | `#A27FC2` | `#BCA3D6` | 8.35 / 7.83 / 6.07       |
| info    | `#5FBEDC`   | `#253539` | `#5FBEDC` | `#7CCEE6` | 10.56 / 9.90 / 7.18      |

### 3.5 使用规则

- 文字只能消费 `--vk-color-<sem>-text`。base 对纸面仅 1.2–2.9:1，直接当文字不合格。
- 指示、边框、浅底可以直接用 base；但当边框是唯一状态线索时（表单非法态、无图标的提示条），亮色改用 `-border`，暗色改用 `-text`。
- 浅底必须配深文字：`-bg` + `-text`，禁止 `-bg` + base。
- 需要状态色时只从这里选，不在组件 CSS 里写十六进制，也不临时调 `color-mix()` 造新色。
- 暗色必须使用暗色块里的对应值，不能靠 `filter` / 反相 / 透明度临时处理。
- 品牌若新增语义色，必须先扩展品牌资源，再改 `theme.json`；本库不引入四色星之外的新色相。

## 6. 使用规则

- 组件 CSS 只消费 `var(--vk-*)`，不写十六进制、`rgb()`、`px` 魔法值（1px 边框与 100% 除外）。
- 新语义令牌先改 `theme.json`，再改组件；`theme.css` 由脚本生成，禁止手改 `dist`。
- `VkConfigProvider` 只向子树注入变量，不写 `:root`；需要全局主题时由使用方显式引入 `@vakao/ui/theme.css`。
- 暗色、品牌换肤都通过令牌完成，组件内不出现主题判断分支。
- 生成脚本会把 `space3`、`textColor1` 这类键名转成 `--vk-space-3`、`--vk-text-color-1`；早期版本曾漏掉数字前的连字符，导致间距与文字色全部取空，现已修正并加入校验。
