# Switch 开关

二元状态切换，使用 `role="switch"` 与 `aria-checked`，支持加载与禁用。

<Demo name="switch/basic" />

## 键盘

原生 `<button>`，`Tab` 到达，`Enter` / `Space` 切换，`focus-visible` 时显示 2px 主色轮廓。

## 引入

```ts
import { VkSwitch } from '@vakao/ui/switch'
import '@vakao/ui/switch/style.css'
```
