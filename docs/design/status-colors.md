# 状态色与对比度

## 映射原则

不新增色相。success / warning / error / info 分别映射四色星的黄、橙、紫、蓝，理由如下：

| 语义      | 颜色         | 理由                                                                                                 |
| --------- | ------------ | ---------------------------------------------------------------------------------------------------- |
| `success` | 黄 `#EDDF55` | 星形四点里黄色最亮，承担"完成 / 通过"的轻盈感；不与主色抢视线                                        |
| `warning` | 橙 `#F0995F` | 橙是四色星里明度最高的暖色，与朱砂主色同族但明度差 30% 以上，且只出现在浅底 + 图标里，不会与按钮混淆 |
| `error`   | 紫 `#A27FC2` | 品牌里唯一足够深的非主色；较深的明度天然适合"阻断"语义，也避免引入红色                               |
| `info`    | 蓝 `#5FBEDC` | 四色星里唯一的冷色，与朱砂主色形成冷暖对照：主色承担操作，蓝色承担陈述与系统提示                     |

主色（朱砂 `#C43A21`）不参与状态表达：状态位只从上表四个色相里取。`warning` 与主色虽然同属暖色，但两者不会出现在同一个视觉位置——主色只做实心按钮与选中态，warning 只做浅底提示与图标。

## 具体值

### 亮色

| 语义    | 主色      | 浅底      | 边框      | 文字      | 文字对比度（对浅底） |
| ------- | --------- | --------- | --------- | --------- | -------------------- |
| success | `#EDDF55` | `#F8F6E2` | `#9C9335` | `#6E6620` | 5.4:1                |
| warning | `#F0995F` | `#F9EDE3` | `#C97F4E` | `#8F5730` | 5.1:1                |
| error   | `#A27FC2` | `#EFEAEF` | `#A27FC2` | `#755A8E` | 4.9:1                |
| info    | `#5FBEDC` | `#E7F2F2` | `#4C9AB3` | `#336D80` | 5.1:1                |

### 暗色

| 语义    | 主色      | 浅底      | 边框      | 文字      | 文字对比度（对浅底） |
| ------- | --------- | --------- | --------- | --------- | -------------------- |
| success | `#EDDF55` | `#3D3A20` | `#EDDF55` | `#EDDF55` | 8.4:1                |
| warning | `#F0995F` | `#402F22` | `#F0995F` | `#F5AC7B` | 6.7:1                |
| error   | `#A27FC2` | `#332B36` | `#A27FC2` | `#BCA3D6` | 6.1:1                |
| info    | `#5FBEDC` | `#253539` | `#5FBEDC` | `#7CCEE6` | 7.2:1                |

黄色在暗色下不适合作为浅底上的文字（明度过高会刺眼），因此 success 的浅底采用同色相压暗的 `#444123`，文字仍用 `#EDDF55`。

## 使用规则

1. **原色**只用于图标、边框、进度条、指示点等非文字场景。
2. **文字**使用 `--vk-color-*-text`；亮色下都是同色相压暗的变体，暗色下重新计算。
3. **浅底**使用 `--vk-color-*-bg`，配合同色系边框，不要叠在卡片上再叠浅底超过两层。
4. **错误态禁止只靠颜色**：必须同时出现图标、文案与边框 / 浅底。Form、Input、Alert 都遵循此规则。

## 令牌清单

```
--vk-color-success / -bg / -border / -text
--vk-color-warning / -bg / -border / -text
--vk-color-error   / -bg / -border / -text
--vk-color-info    / -bg / -border / -text
```

## 使用者

| 令牌    | 消费者                                                                         |
| ------- | ------------------------------------------------------------------------------ |
| success | Form 校验通过、Alert、Progress、Table 状态列                                   |
| warning | Form 警告、Alert、InputNumber 越界提示                                         |
| error   | Form 校验失败、Input / Select / InputNumber 错误态、Alert、Popconfirm 危险操作 |
| info    | Alert 默认态、Empty 提示、Toast / Message                                      |
